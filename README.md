## 📝 Descrição do Projeto

O Projeto Suriname é um site informativo e turístico sobre o país do Suriname. O site foi desenvolvido como trabalho prático para a disciplina de Fundamentos da Web, com o objetivo de apresentar a história, a cultura e os principais pontos turísticos do país de forma visual, responsiva e acessível.

O projeto utiliza o framework **Bootstrap** para garantir que o layout seja adaptável a diferentes tamanhos de tela (desktops, tablets e celulares) e conta com seções detalhadas sobre:
- **História**: A colonização, independência e os conflitos étnicos do país.
- **Cultura**: Linguagem, população, música, esportes, costumes e cerimônias.
- **Turismo**: Detalhamento de locais como o Templo Arya Dewaker, a Catedral St. Peter and Paul, o Palácio Presidencial, Jodensavanne, a Praça da Independência, o Parque Paperpot e o Forte Nieuw Amsterdam.

## 🏃‍♂️ Como Executar o Projeto

Como o projeto é feito inteiramente com HTML, CSS e Bootstrap (via CDN), não há necessidade de instalar dependências ou rodar servidores.

1. Faça o download ou clone este repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge, etc.).
3. Navegue pelas abas do menu superior para explorar as páginas.
